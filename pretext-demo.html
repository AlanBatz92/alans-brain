What is PreText?

A pure-TypeScript text measurement library by chenglou (ex-React core team, Midjourney). It measures text dimensions without touching the DOM — no reflows, no layout thrashing. The prepare() call caches segment widths via canvas, then layout() is pure arithmetic.

What's happening here?

The transcript text is measured by PreText to build a precise character grid. Each frame, mouse position or webcam brightness drives which characters glow. The grid layout is computed once; only the visual effect runs per-frame — exactly the kind of separation PreText enables.

Why does this matter?

Normally, measuring text = expensive DOM reflows. PreText decouples measurement from rendering. This means virtualized lists, masonry layouts, and wild visual effects like this one become fast and jank-free. One prepare(), infinite layout() calls at ~0.0002ms each.
